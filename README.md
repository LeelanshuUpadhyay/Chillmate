# ChillMate - Smart Water Bottle Website

**ChillMate** is a smart water bottle designed for students, professionals, and fitness enthusiasts. It combines hydration, music, and convenience in a sleek, modern design.

## 🌟 Features
- **Cooling Fan**: Hidden smart fan cools your water instantly.  
- **Bluetooth Speaker**: Enjoy music while staying hydrated.  
- **Medicine Box**: Compact compartment for essentials and medicines.
